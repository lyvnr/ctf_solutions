[6] VULNERABILITY ANALYSIS
================================================================================

CVE          : CVE-2015-3306
Component    : ProFTPD 1.3.5 mod_copy module
Risk         : HIGH — Unauthenticated file copy to arbitrary locations
Disclosure   : 2015-04-01

Description:
  The mod_copy module in ProFTPD 1.3.5 allows remote attackers to read and
  write files to arbitrary locations via SITE CPFR and SITE CPTO commands,
  without requiring authentication. This was chained with an exposed NFS mount
  to exfiltrate Kenobi's SSH private key.

Contributing factors on this machine:
  1. ProFTPD 1.3.5 with mod_copy enabled and unauthenticated access
  2. NFS /var share exposed world-wide (no host restriction)
  3. Custom SUID binary (/usr/bin/menu) calling commands without full paths
  4. Predictable file locations (SSH key at default path)
